# Glossary — the fixed terms

**Status:** design · glossary — the one place terms are defined.
**Date:** 2026-10-23.

**Related:** [vision](vision.md) · [the cube](systems/cube.md) · [resources](systems/resources.md)

One term per idea. In-game copy uses the plain terms; the physics names stay internal.
**No other physics jargon** (no Schwarzschild, Lense-Thirring, etc.).

| Term | Means |
|---|---|
| **Our Space** | The game's name (your space + outer space). |
| **the cube** | The one instrument — a tangible MR tool moved over the bubble ([the cube](systems/cube.md)). |
| **zone** | The region of space the cube covers; the unit a scale is applied to. |
| **the scale** | The verb: a two-hand pinch *inside* the cube, scaling the space and the content. |
| **the region** | The cube's frame (edges/corners) — *where* you work; resized separately from the scale. |
| **the lens** | The cube frame + the grab-inside scale, taken together (the mechanic under test). |
| **rotate** | The spin gesture (job 4) — frame dragging. |
| **the Wrap** | The in-fiction system that wraps spacetime (the tech team's product). |
| **shaping** | The in-game verb for using the Wrap. |
| **entropy** | The bar: the Wrap's cost. Every edit burns it; the grade is what is left. |
| **eco rating** | The flavour name for the entropy grade (stars). |
| **the window** | `[Tmin, Tmax]` — the ship-time band the delivery must arrive inside. |
| **the ship's clock** | Ship proper time; slows deep in a well. |
| **fuel** | The launch you are *given* (the brief) — not a player lever. **Global for now**; per-job later. |
| **spin** | The surfaced word for a rotating source (frame dragging). |
| **stars** | The 1–3 grade from entropy left. |
| **the field** | The derived acceleration/potential the ship flies through. |
| **bubble** | The playfield: the miniature universe anchored in the room. |
| **Room / Bubble** | The two MR views (room-scale vs the scaled bubble). |
