# Parked

Plans that are **not current** and **collide with the current framing**. They are kept
for reference, not scheduled. Move a plan back to `backlog/` if the framing changes.

The current framing is the **lens**
([project direction](../../design/project-direction.md)): the player scales zones (the
space and the content) with the cube, and the ship flies the deformed spacetime. Anything
that assumes a different verb (planet-dragging), route model, or a management loop is parked
here.
