# Parked

Plans that are **not current** and **collide with the current framing**. They are kept
for reference, not scheduled. Move a plan back to `backlog/` if the framing changes.

The current framing is [space shaping](../backlog/gameplay/space-shaping-future.md):
the player moves planets and their forces bend a ship's constant launch. Anything that
assumes a different route model or a management loop is parked here.

| Plan | Why parked |
|---|---|
| [Planet route drawing](planet-route-drawing.md) | Drawn routes are replaced by shaping space; the path is emergent from the field, not drawn. |
| [Ambient round activation](universe-ambient-round-activation.md) | A management game (rounds activate decor planets, growing pool), not the physics puzzle. |
